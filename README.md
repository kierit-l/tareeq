# طريق Tareeq

Arabic-first, SMS-first road status and honest trip times for Gaza: *"Can I get there safely today, and how long will it really take?"*

Hackathon build for the Deir al-Balah ↔ Khan Younis ↔ Al-Mawasi corridor. Reports, fares and waits are **simulated**, and the no-go polygons are **illustrative, not real safety data**.

- [`tareeq/`](tareeq/): the app (FastAPI backend, Leaflet web map, SMS/WhatsApp webhook, operator console, field reporting). Run instructions are in [`tareeq/README.md`](tareeq/README.md).
- [`Tareeq — Product Spec v2.md`](<Tareeq — Product Spec v2.md>): current spec. It covers where the build stands and what the pilot needs.
- [`Gaza Transit Info — Product Spec.md`](<Gaza Transit Info — Product Spec.md>): original spec (superseded by v2).
